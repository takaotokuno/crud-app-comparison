# 今日やったことまとめ
SQL Serverを使った、EF Core Migrationsを動かせる環境を整備

.NET 8 から 9 へ更新。
Microsoft.AspNetCore.OpenApi, EntityFrameworkCore.SqlServer, EntityFrameworkCore.Design, dotnet-ef を9で統一した。

```bash
dotnet ef migrations add InitialCreate

dotnet ef database update
```
で初期マイグレーションを作成

## 詰まったところ
dotnet ef が使えなかったため、Dev Container の post-create.sh で dotnet-ef を復元・インストールするようにした。
Dev Container 内に docker コマンドがなかったため、docker-outside-of-docker feature を追加した。
その際、Yarn の古い apt repository が原因で GPG エラーが発生したため、（.NET 9 開発環境のイメージに入っていた？）
.devcontainer/Dockerfile で不要な Yarn repo を削除する対応を入れた。

SQL Server への接続で TCP Provider, error: 40 が発生した。
原因は以前にもやらかした、 Dev Container と DB コンテナが別ネットワークにいたことだった。

## Docker Compose の方針
開発中は、基本的に db と devcontainer を Compose で起動する。
backend と frontend は Dev Container 内で手動起動する。

## CI対応
Entity や DbContext を変更したのに Migration を作り忘れる事故を防ぐため、CIに以下のチェックを入れる方針にした。
```bash
dotnet ef migrations has-pending-model-changes
```
